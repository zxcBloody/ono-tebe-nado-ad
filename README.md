# Оно тебе надо

Репозиторий проекта: https://github.com/zxcBloody/ono-tebe-nado-ad

Учебный проект: адаптированная под ширину 1100 px вёрстка главной страницы аукциона вещей, в которые никто не верил.

## О проекте

Страница сверстана по макету в Figma. Она состоит из нескольких блоков:

- шапка с меню, логотипом и контактами;
- обложка с заголовком и кнопкой «Сделать ставку»;
- блок «Лоты» с тремя карточками;
- блок «Об аукционе»;
- подвал с контактами, меню и ссылками на соцсети.

## Используемые технологии

- HTML5 (семантическая разметка)
- CSS3 (Flexbox, Grid, методология БЭМ)
- Шрифт Raleway (подключён локально)

## Структура проекта

```
├── fonts/        # шрифты Raleway и fonts.css
├── images/       # изображения и иконки
├── styles/       # global.css и style.css
└── index.html    # главная страница
```

## Как посмотреть

Скачайте или склонируйте репозиторий и откройте файл `index.html` в браузере.

```
git clone https://github.com/zxcBloody/ono-tebe-nado-ad.git
```
